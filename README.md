# Financial Time Series ML Analysis: Ethereum vs. Novo Nordisk

This project compares Ethereum and Novo Nordisk using descriptive analytics, unsupervised learning, and classification models.

## Project question
Can return and volatility patterns, regime diagnostics, and engineered market features help explain or predict short-horizon return direction?

## Methods
- Data cleaning and preprocessing
- Return on investment (ROI) analysis
- Volatility analysis
- Gaussian Mixture Models for regime detection
- Isolation Forest for anomaly detection
- Hidden Markov Models for crash-probability estimation
- Decision Trees and XGBoost for return-direction prediction

## Main tools
- Python
- pandas
- matplotlib
- scikit-learn
- xgboost
- hmmlearn

## Repository structure
- `financial_time_series_ml_analysis_cleaned.ipynb` — main analysis notebook
- `README.md` — project overview
